# Stock Data Analysis

A Python data analysis project focused on extracting and visualizing historical stock price and quarterly revenue data for Tesla (TSLA) and GameStop (GME).

## Project Overview

This project demonstrates the process of collecting, cleaning, and visualizing financial data using Python. It includes both API-based data extraction and web scraping.

### Tasks Completed

* Extracted historical Tesla stock data using `yfinance`
* Extracted Tesla quarterly revenue data through web scraping
* Extracted historical GameStop stock data using `yfinance`
* Extracted GameStop quarterly revenue data through web scraping
* Cleaned and organized revenue data using `Pandas`
* Created stock price and revenue visualizations using `Matplotlib`

## Tools & Libraries

* Python
* Pandas
* yfinance
* Requests
* BeautifulSoup
* Matplotlib
